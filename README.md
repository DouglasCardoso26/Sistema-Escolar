# 📘 Atividade 04 – Criação e Manipulação de Dados com SQL

Este repositório contém os scripts SQL desenvolvidos para a Atividade 4, referentes ao mini-mundo *Sistema Escolar*.

## 📂 Arquivos incluídos

### **1️⃣ 00_criacao_tabelas.sql**
- Criação do banco `sistema_escolar`
- Criação das tabelas:
  - aluno  
  - professor  
  - diretor  
  - turma  
  - nota  
- Definição de chaves primárias e estrangeiras

---

### **2️⃣ 01_inserts.sql**
Contém todos os comandos `INSERT INTO` para popular:

- Alunos  
- Professores  
- Diretores  
- Turmas  
- Notas  

---

### **3️⃣ 02_selects.sql**
Consultas SQL utilizando:

- `SELECT DISTINCT`
- `ORDER BY`, `LIMIT`
- `JOIN`
- `WHERE`
- Funções de agregação: `AVG`, `COUNT`, `ROUND`
- `GROUP BY`

---

### **4️⃣ 03_updates_deletes.sql**
Comandos de atualização e remoção:

- `UPDATE` com filtros  
- `DELETE` com filtros  
- Desativação do modo seguro:

---

## 🚀 Como executar

1. Abra o MySQL Workbench  
2. Execute `00_criacao_tabelas.sql`  
3. Execute `01_inserts.sql`  
4. Execute `02_selects.sql`  
5. Execute `03_updates_deletes.sql`

---

## ✔ Requisitos atendidos

- Scripts organizados em arquivos separados  
- Manipulação completa de dados (INSERT, SELECT, UPDATE, DELETE)  
- Uso de joins, filtros, ordenação e agregação  
- Estrutura coerente com o mini-mundo fornecido

---

## 👨‍🏫 Observação
Todos os scripts foram testados em ambiente MySQL 8.0 e executam sem erros.
